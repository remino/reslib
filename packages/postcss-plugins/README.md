# @remino/postcss-plugins

Grab bag of PostCSS helpers:

- `addDvh()` – clones `vh` declarations with `dvh` fallbacks.
- `addLvh()` – clones `vh` declarations with `lvh` fallbacks.
- `addFontVariation()` – derives `font-variation-settings` from `font-weight`.

Each plugin is available from the root entry point or via their dedicated sub-paths.
